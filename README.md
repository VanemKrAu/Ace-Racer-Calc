## 📖 项目简介
面向网易手游《王牌竞速》的高精度能量运算工具，三轨并行测算：
1. **首发一大（一气首大）**：判断开局是否能直接满能量释放首个大招；
2. **后续大招无限循环**：判断大招持续期间能否自洽充能、实现无限连发；
3. **开局连发（二大 / 三大）**：一大溢出的能量带进二大、二大溢出的能量带进三大，判断开局能否连放三个大招。

页面顶部可在三种计算模式之间切换：

| 模式 | 用途 |
| --- | --- |
| **先机汇能** | 辅助、单刷车计算：先机、汇能芯片怎么配才能首发、循环 |
| **团魂获能** | 组队时我获得的能量：团魂 + 增益装置或队友辅助，并入首发、循环与连发判定 |
| **辅助供能** | 我开辅助车时给队友充能：选一辆辅助车，算出队友实收多少 |

## ✨ 核心功能
- 196 辆赛车全量数据库（含品质/定位/专精/芯片槽），一键选择自动填充
- 中英文名搜索 + 拼音首字母搜索（如 `lc`→罗刹、`XY`→逍遥）
- 车辆列表按入库时间排序，新车自动置顶
- 6 种氮气规格等比同步换算
- 智能芯片联动面板
  - 先机汇能：改一项，另一项按首发自动反算
  - 团魂获能：团魂 / 先机 / 汇能三值联动，每一项都能单独锁定（手填即上锁，锁定 = 不再自动反算，仍可修改）；团魂优先、只补首发缺口，上限 200%；团魂锁定后由汇能保循环、先机补首发；装循环装置时优先反算汇能与先机
- 增益装置：循环装置 / 充能装置 / 超级充能装置（限装 1 个；装上后反制与充能效率降低归零并锁定，卸下恢复）
- 队友辅助：47 辆辅助车的辅助充能自动读取（大招开始时一次 / 大招期间每秒 / 每次用氮 / 直接补满一管）
- 七大赋能系统矩阵（主要、次要赋能各最多激活 1 个）
- 对手反制干扰模拟（0% ~ 18%）
- 实时三轨测算引擎（首发 + 循环 + 开局连发），逐项运算解析盒；没达成时直接给出「最少要多少」，照填即可达成
- 底部结果速览栏：随时看到首发 / 循环（或供能）结果，点一下跳到对应结果卡
- 深色/浅色/跟随系统三主题，中英双语切换
- PWA 离线缓存、分享链接（含锁定状态）/ 长图 / 文字配置单导出、SEO 优化

## 🚀 使用方法
>本地使用
1. 下载整个项目目录（`index.html` 需与 `car-database.js`、`html2canvas.min.js`、图标文件同目录），双击 `index.html` 打开
2. 在页面顶部选择计算模式（先机汇能 / 团魂获能 / 辅助供能）
3. 选择车辆，填写芯片、赋能配置；团魂获能下再选增益装置或队友辅助车
4. 查看首发、循环与开局连发的实时测算结果
5. 根据 ❌/✅ 提示和给出的「最少要多少」调整配装
>云端使用
- 直接访问我的演示网站：[王牌竞速 - 大招能量计算器](https://aceracercalc.top/)
