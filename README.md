> **王牌竞速芯片计算器 (Ace Racer Chip Calculator)** 是由 **[Vanem](https://v.douyin.com/AEe8wPEHZp0/)** 独立设定全部交互逻辑与底层计算公式、AI 辅助开发的赛车能量与芯片计算工具。致力于帮助玩家精准推导各类赛车在单刷、排位与组队实战下的首发与大招循环机制，彻底告别盲目配装。

## 📖 项目简介

本工具针对《王牌竞速》复杂的底层能量机制，提供**三轨并行测算引擎**：
1. **首发一大（一气首大）**：判定起步固定充能 + 首发氮气与自充能否直接达到大招释放阈值；
2. **后续大招无限循环**：判定大招持续期内释放氮气、被动自充及增益产出能否实现 100% 自洽回满；
3. **开局连发测算（三大连发）**：考虑首发溢出带入二大、二大溢出带入三大，并整合特殊芯片在大招释放时的即时产出，精准定位断档点并给出达成三连发所需的最小芯片建议值。

页面顶部提供三种专属计算模式一键切换：

| 计算模式 | 适用场景与核心逻辑 |
| :--- | :--- |
| **先机汇能** | **单人单刷 / 辅助车基准测算**：先机、汇能双值实时联动，改动一项自动高精度反算另一项。 |
| **团魂获能** | **组队排位实战测算**：团魂 / 先机 / 汇能三值联动；能量来源在排位增益装置（循环/充能/超充/加速）与队友辅助之间二选一，自动识别装置特性并进行芯片解算。 |
| **辅助供能** | **辅助车供能视角**：选择一辆辅助车，自动解析其大招机制（首发/循环/每秒/单氮气/补满一管），测算出队友实收能量。 |

## ✨ 核心特色功能

### 🏆 社区与国服方案库系统
- **挂载于选车正下方**：玩家在顶部完成赛车选择后，视线顺流自然下移即可立即浏览该赛车专属方案库；
- **官方解密国服顶尖配装**：集成游戏内提取的官方高清黑面罩冰晶皇冠头盔勋标，高保真还原国服车神排位专属芯片解；勋标直接悬浮展示（无外框、无多余底色，设计语言与全站纯净对齐）；
- **车友社区互动与匿名分享**：支持车友收藏个人专属方案，可一键匿名分享至全网社区（匿名上传免除个人隐私填写，自动脱敏署名为“热心车友”）；
- **方案数据安全与本地管理**：支持保存本地方案与多参数完整预览展示（涵盖反制/干扰降效、特殊芯片及口径选项、增益装置、赋能子项、扩展自充能与车辆基础微调），支持一键套用配装与撤销恢复，并支持一键复制国服车友游戏 ID；
- **代码层物理防滥用阻断（PlanValidator）**：严密过滤违规配置（如开局/循环填一二十个氮气直接物理拦截并弹出清晰阻断原因；**团魂作为合法机制无论填多少均绝对豁免放行**）；
- **社区方案库互动、筛选与安全合规审核**：支持车友匿名分享配装、按「全部 / 先机汇能 / 团魂获能」筛选、固定视口懒加载、点赞 / 取消赞与全站公告弹窗；支持车友提交国服荣誉截图自证入选国服顶尖精选，审核状态与说明直接在车友端查看；
- **纯静态前端开源隔离**：本仓库仅托管纯静态前端页面与公开设计规范（核心计算器与本地方案可完全离线运行），开源仓库零凭据、零私密内容泄露。

### ⚡ 全新全赋能系统矩阵（核心 12 + 次要 12）
- **四大派系全收录**：涵盖创造、防御、战斗、能量四大派系共 24 项赋能机制；
- **核心与次要双位体系**：支持同时装配 1 个核心赋能 + 1 个次要赋能；
- **同系互斥变灰呈现**：选中任意核心或次要赋能后，同系其余赋能自动进入半透明禁用态（变灰不可点），杜绝非法冲突；
- **智能冲突解决逻辑**：若先选择次要赋能，随后选择冲突的核心赋能时，系统以核心赋能为优先，自动清空冲突的次要赋能并弹出 Toast 温馨提示；
- **实战频次联动测算**：节奏赋能等专属效果支持精确配置首发触发次数与循环内触发次数，实时并入大招能量流计算；
- **排位增益装置自动锁定**：装配排位装置时遵循排位官方规则，全赋能矩阵自动归零锁定变灰（带 `[🔒 已锁定]` 标签），卸下后自动精准恢复原先选项。

### 🏎️ 198 辆全量赛车数据库
- 涵盖游戏内全部 198 辆赛车（含最新上线车辆，如 12104 炎龙驹），新车自动置顶；
- 独家收录**真实芯片孔型槽位（`chip_slots`）**、品质、定位、专精、基础双充、大招与氮气时长；
- 支持中英文名搜索及拼音首字母模糊检索（如输入 `ylj` 搜索炎龙驹、`lc` 搜索罗刹、`XY` 搜索逍遥）；
- 选中赛车一键自动填充基础参数（起步、氮气基础充能、大招阈值与自充数值等）。

### 🧩 深度芯片装配与特殊芯片系统
- **动态孔型匹配**：还原赛车真实的 6 槽芯片布局（圆形、菱形、六边形、十字形、V 型槽）；
- **动态多 V 槽支持**：智能检测车辆实际 V 槽数量并放开上限（支持布加迪 Bolide、兰博基尼 Veneno 等双 V 槽赛车同时装配两枚特殊芯片）；
- **实装 9 枚特殊核心芯片（车姬 / 至尊 / 超频三大分类）**：
  - **车姬芯片**：**隐匿猎手之芯**（大招释放时为下一大充能 +16%，自动注入开局二大运算链）、**猫眠梦之芯**（每 6 秒集气与耐力恢复，大招阈值动态降至 90% / 猫眠梦 66%）；
  - **至尊与超频芯片**：实装「铁血硬汉」「三联动力」「青龙之芯」「傲梅之芯」「修竹之芯」「逸菊之芯」「秀华之芯」共 7 枚特殊核心芯片，精确匹配车型适用范围与满级公式。
- 芯片浮窗卡片支持自定义核心数值微调。

### 🛡️ 全局环境与实战模拟
- **队友辅助系统**：自动读取 47 辆辅助车的辅助充能机制与数值；
- **对手反制干扰设定**：全局实战反制比例（0% ~ 18% 双轨模拟）与充能效率降低模拟；
- **氮气规格换算**：支持 1x5、1x6、2x2、2x3、2x25、3x2 共 6 种规格等比时长与能量自动换算。

### 🎨 现代化交互与全端排版美学
- **全站连续曲率圆角美学**：所有卡片、面板、输入框、按钮、徽标与弹窗圆角均升级为 `corner-shape: squircle` 连续曲率圆角（并在支持的浏览器自动匹配视觉半径补偿），旧版归档页同步覆盖；
- **全站统一 Web Animations API 高度过渡**：卡片折叠与展开统一由 `window.__pvMorph` 驱动，顺滑贝塞尔高度插值与直接子项渐入淡出，彻底消除生硬断层与“吭一下”弹开；
- **移动端舒适折叠流**：手机模式下全赋能列表限制最大舒适高度（400px）并支持原生顺滑触控滑动，杜绝 1500px 巨幅突冲砸落；
- **左上角草稿独立管理**：菜单内提供【自动保存/恢复草稿】独立开关，用户可自主决定刷新时是否恢复未保存配置；
- **全端主题与多语言**：深色（默认） / 浅色两套高保真主题（带液态过渡动效），支持中文 / English 完整双语切换；
- **便捷分享与导出**：支持通过 URL 完整序列化当前所有配置，支持一键导出高清长截图与文字配置单；
- **前端开发规范指引**：项目开发严格遵循根目录下的 [UI-SPEC.md](UI-SPEC.md) 与 [AGENTS.md](AGENTS.md)。
