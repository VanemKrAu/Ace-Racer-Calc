> **王牌竞速芯片计算器 (Ace Racer Chip Calculator)** 是由 **[Vanem](https://v.douyin.com/AEe8wPEHZp0/)** 独立设定全部交互逻辑与底层计算公式、AI 辅助开发的赛车能量与芯片计算工具。致力于帮助玩家精准推导各类赛车在单刷、排位与组队实战下的首发与大招循环机制，彻底告别盲目配装。

## 📖 项目简介

本工具针对《王牌竞速》复杂的底层能量机制，提供**三轨并行测算引擎**：
1. **首发一大（一气首大）**：判定起步固定充能 + 首发氮气与自充能否直接达到大招释放阈值；
2. **后续大招无限循环**：判定大招持续期内释放氮气、被动自充及增益产出能否实现 100% 自洽回满；
3. **开局连发测算（三大连发）**：考虑首发溢出带入二大、二大溢出带入三大，并整合特殊芯片在大招释放时的即时产出，精准定位断档点并给出达成三连发所需的最小芯片建议值。

页面顶部提供三种专属计算模式一键切换：

| 计算模式 | 适用场景与核心逻辑 |
| :--- | :--- |
| **先机汇能** | **单人单刷 / 辅助车基准测算**：先机、汇能双值实时联动，改动一项自动高精度反算另一项。 |
| **团魂获能** | **组队排位实战测算**：团魂 / 先机 / 汇能三值联动；能量来源在排位增益装置（循环/充能/超充/加速）与队友辅助之间二选一，自动识别装置特性并进行芯片解算。 |
| **辅助供能** | **辅助车供能视角**：选择一辆辅助车，自动解析其大招机制（首发/循环/每秒/单氮气/补满一管），测算出队友实收能量。 |

## ✨ 核心特色功能

### 🏎️ 197 辆全量赛车数据库
- 涵盖游戏内全部 197 辆赛车（含最新上线车辆），按入库时间排序，新车自动置顶；
- 独家收录**真实芯片孔型槽位（`chip_slots`）**、品质、定位、专精、基础双充、大招与氮气时长；
- 支持中英文名搜索及拼音首字母模糊检索（如输入 `ylj` 搜索炎龙驹、`lc` 搜索罗刹、`XY` 搜索逍遥）；
- 选中赛车一键自动填充基础参数（起步、氮气基础充能、大招阈值与自充数值等）。

### 🧩 深度芯片装配与特殊芯片系统
- **动态孔型匹配**：还原赛车真实的 6 槽芯片布局（圆形、菱形、六边形、十字形、V 型槽）；
- **动态多 V 槽支持**：智能检测车辆实际 V 槽数量并放开上限（支持布加迪 Bolide、兰博基尼 Veneno 等双 V 槽赛车同时装配两枚特殊芯片）；
- **实装特殊核心芯片**：
  - **隐匿猎手之芯**：大招释放时为下一大充能 +16%（自动注入开局二大运算链）；
  - **猫眠梦之芯**：每 6 秒获得 1200 集气量并恢复 6 点耐久值，大招阈值动态降低（普通赛车降低至 90%，猫眠梦装配时降至 66%）；
- 芯片浮窗卡片支持自定义核心数值微调。

### ⚡ 排位专属增益装置矩阵
- 完整支持游戏排位赛四大增益装置：
  - **循环装置**：每次放氮气固定获得 +13% 能量（不受团魂、反制、充能效率影响，汇能核心搭档）；
  - **充能装置**：开局第 5s、16s 及每 13s 获得 +34% 辅助充能；
  - **超级充能装置**：开局第 5s、16s 及每 13s 获得 +48% 辅助充能；
  - **加速装置**：局内极速 +24km/h，首个大招达到 80% 能量即可释放（只降低首发阈值，不提供充能）；
- **排位机制还原与环境联动**：装配增益装置时，系统自动遵循排位赛（无干扰车、无赋能）规则，将「对手反制」与「七大赋能」自动归零并锁定变灰（右上角统一呈现精致的 `[🔒 已锁定]` 胶囊标签）；卸下装置后自动复原原数值；
- **加速装置专属反算解**：装备加速装置时，自动按首发 80% 阈值求解芯片需求，消除溢出浪费。

### ⚙️ 智能芯片联动与高精度反算
- **先机 ↔ 汇能双向联动**：锁定目标及格线，修改先机自动推导最小汇能，反之亦然；
- **团魂三值智能求解**：团魂、先机、汇能各具独立锁止状态；手填即上锁，未锁项自动求解首发或循环的最优芯片解；
- **芯片建议值扫描**：当开局连发断档时，算法自动扫描推导出「连放三大最少要达到的先机/汇能/团魂阈值」，照填即可保证三大连发跑通。

### 🛡️ 全局环境与实战模拟
- **队友辅助系统**：自动读取 47 辆辅助车的辅助充能机制与数值；
- **七大赋能系统矩阵**：复苏之泉、拒绝溢出、节奏赋能、能源回收、未来视界（90% 降维）、缺一不可、花信风；
- **对手反制干扰设定**：全局实战反制比例（0% ~ 18% 双轨模拟）与充能效率降低模拟；
- **氮气规格换算**：支持 1x5、1x6、2x2、2x3、2x25、3x2 共 6 种规格等比时长与能量自动换算。

### 🎨 现代化交互与多端适配
- **逐项透明解析盒**：提供【首发大招运算解析盒】、【大招循环运算解析盒】与【开局连发运算解析盒】，透明展示每一步的公式推导；
- **移动端渐进披露**：针对手机屏幕采用无损折叠设计，展开收起带顺滑动画；
- **全端主题与多语言**：深色 / 浅色 / 跟随系统三套高保真主题，支持中文 / English 完整双语切换；
- **便捷分享与导出**：支持通过 URL 完整序列化当前所有车辆与芯片配置（一键分享配置链接），支持一键导出高清长截图与文字配置单。
